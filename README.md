# かじわらタワーバトル　v3.0.2

キャラを積み上げて、**落とした方が負け**のバランス積みゲームです。

**遊ぶ：https://akionlywork-dot.github.io/kajiwara-tower-battle/**

スマホのブラウザ（縦画面）向け。HTML / CSS / JavaScript だけで動き、ビルドは不要です。

---

## 1. 遊び方

### 操作

1. 画面上部にキャラが出ます
2. 画面を指で**左右にドラッグ**して、落とす位置を決めます
3. **「回転」**ボタンで45度ずつ回せます。**「反転」**ボタンで左右を入れかえられます（見た目の画像と当たり判定の両方が反転します。くるっと裏返るアニメーションつき。CPU も反転を使い、オンライン対戦では反転も相手に伝わります）
4. **「落とす」**ボタンで落とします
   （設定で「指を離したら落とす」をONにすると、ドラッグして指を離すだけで落ちます）
5. 全部のキャラが止まったら、次のキャラが出ます
6. 土台から1体でも落ちたらゲーム終了

右上の ❚❚ ボタンでポーズできます。ほかのアプリに切りかえたときも自動でポーズします。

**パソコン（マウス・キーボード）**

| 操作 | マウス | キーボード |
| --- | --- | --- |
| 動かす | カーソルを左右に動かすだけ（ドラッグしなくてよい） | ← → / A D（押しっぱなしで動き続ける。Shift を押しながらで細かく） |
| 回転（45度ずつ） | 右クリック / ホイール（下に回すと右回り、上に回すと左回り） | ↑ / W / E：右回り、Q：左回り |
| 落とす | 左クリック | スペース / Enter |
| ポーズ | | Esc / P（ポーズ中の Esc・P で再開） |

- キーの割り当ては `js/controls.js` の `KEYS` にまとめてあります（変えると、設定画面の「操作方法」と、ゲーム中のヒントの表示も変わります）
- 誤って落とさないよう、ゲームの場の外（左右の背景）・画面の上のスコアのあたり・キャラが出てすぐのクリックでは落としません
- マウスでは「指を離したら落とす」の設定に関係なく、いつもクリックで落とします。指・ペンの操作は、今までどおりドラッグです
- メニューは Tab で選べ（選んでいるボタンに黄色の枠が出る）、Enter で押せます。Esc は「もどる」と同じ。ダイアログは Enter で OK、Esc でキャンセル
- 文字を入力している間（名前・ルームコードなど）は、ゲームのキーは反応しません。相手の番・CPU の番・ポーズ中も、画面のボタンと同じく操作できません
- キーやマウスを初めて使ったときに、画面の下に操作のヒントが少し出ます。設定画面の「操作方法」に、マウス・キーの一覧があります（パソコンのときだけ）
- パソコン向けにするかは、機種名ではなく、画面の幅と「マウスなど細かく指せる機器か」（`(hover: hover) and (pointer: fine)`）で決めます

**パソコンの横長の画面**（幅 1024px 以上・横長・マウスなどのとき）

- 背景（空・雲・地面）が画面いっぱいに広がり、ゲームの場はまん中です。**ゲームの場の大きさ・土台・物理はスマホと同じ**です（場の幅は「画面の高さ × 9/16」まで。広い分は背景だけ。`js/game.js` の `fieldLeft`・`fieldW`）
- 場の左にスコア・積んだ数・高さ・ハイスコア、右に対戦の2人と手番・制限時間・操作の一覧が出ます（上の表示と下の操作ボタンは出しません）
- メニュー・設定などの画面は、最大の幅を決めてまん中に。図鑑は6列、実績・称号は2列に並びます
- ランキングは1列で、1人分の行を表のように横に並べます（順位 ｜ アイコン ｜ 名前・称号 ｜ スコア ｜ 積んだ数 ｜ 高さ ｜ 記録した日。上に見出し、数字は右ぞろえ）
- 幅が中くらい（700〜1023px。タブレットなど）では、今の縦長の表示を少し広くします

### モード

タイトルの「スタート」→ モード選択画面で「ひとりで」か「たいせん」を選びます（ハロウィンなどのイベント期間中は、イベントのボタンも出ます）。

| モード | ルール |
| --- | --- |
| ひとりで → スコアアタック | ひとりでハイスコアに挑戦（ふつうのルール）。スコア ＝ 積んだ数 × 100点 ＋ 高さ 1m × 100点。**ランキング（フリー）対象** |
| ひとりで → 競技 | みんなが同じ条件で競う、公平なルール（下の「競技モード」）。**ランキング（競技）対象**。図鑑には登録されない |
| ひとりで → 特殊ルール | 風・傾く土台・つるつる・ジャイアント（期間中は期間限定ルールも）。ハイスコアはルールごとに記録（ランキングには載らない） |
| たいせん → ともだちと | 1台のスマホを交互に操作。落とした人の負け。**いつも制限時間あり**（1手 15秒。`config.js` の `versus.turnTimeLimit`。時間切れになると、その場で自動で落ちる） |
| たいせん → CPUと | CPU（よわい・ふつう・つよい）と交互に積む。CPU は置き方を試算して、強いほど安定する置き方を選ぶ |
| たいせん → オンライン対戦 | 2台のスマホで対戦（下記） |

- **ひとりで**のボタンには、スコアアタックのハイスコアが小さく出ます。押すと、モードを選ぶ画面「ひとりで」になります（いちばん上に「スコアアタック」、そのすぐ下に「競技」、その下に見出し「特殊ルール」で区切って特殊ルール4つ。それぞれのハイスコアも出ます）
- 「スコアアタック」と呼ぶのは、ふつうのルールだけです（特殊ルールは「特殊ルール「風」」のように呼びます）
- 遊んだあとの「もう一度」は、同じルールですぐに始まります（ルール選択には戻りません）

対戦の先攻は、毎回ランダムに決まります（最初に「〇〇 の先攻！」と表示）。

### 競技モード

「ひとりで」の「競技」（「ランキング（競技）対象」の札）は、みんなが同じ条件で競うためのルールです。設定は `config.js` の `competitive` にまとめてあります。

| 項目 | 競技のルール | config.js |
| --- | --- | --- |
| 出てくるキャラ | ★1〜★3 の、標準の大きさのキャラだけ（今は12体）。サイズ違い（ミニ・ビッグ）・★4・★5・期間限定のキャラは出ない | `rarities` |
| 確率 | 全キャラ同じ確率（レア度・`weight` を使わない）。同じキャラが2回続けて出ない決まりは、ふだんと同じ | `equalChance` |
| 大きさ | 全キャラ標準の大きさ（特殊ルール「ジャイアント」のような倍率なし） | `scale` |
| 点数 | 積んだ数 × 100点（どのキャラも同じ）＋ 高さ 1m × 100点 | `perPiece`・`perMeter` |
| ギミック | 特殊ルールのギミックはなし | |

- 競技で出たキャラは、**図鑑に登録されません**
- 競技では、キャラの**エフェクトを全部出しません**（レア度のオーラ・光・ふち・キラキラ・光の粒、★5 の着地の演出、「レア！」の表示・画面が光る演出・レアの効果音）。全キャラ画像そのままの、同じ見た目です（リザルトカードの画像・フォトモードも同じ）
- 初めて「競技」を押したときは、ルールと「図鑑には登録されません」の説明が出ます（「次から表示しない」に印を付けると、もう出ません）
- 競技のハイスコアは、スコアアタック（フリー）とは別に記録します（`Save.data.stats.compBest`。データのバックアップにも入ります）。戦績画面にも「🏁 競技」の欄があります
- ゲーム中・リザルト・リザルトカードには「🏁 競技」の札が出ます
- 実績：スコアの実績（1000点突破など）・積んだ数や高さの実績・プレイ回数には数えます。**図鑑の実績と、レア度の実績（レアハンター・光と闇・まぼろしとの遭遇など）には数えません**（全キャラ同じ確率だと、レアがすぐ出てしまうため）
- `perPiece`・`perMeter` を変えたときは、`server/ranking.gs` の `COMP_PER_PIECE`・`COMP_PER_METER` も同じ数にして、デプロイしなおします

### オンライン対戦

1. 片方が「部屋を作る」を押すと、6桁のルームコードが出る
2. もう片方が「部屋に入る」でそのコードを入力すると、対戦が始まる（先攻は毎回ランダム）

- 試合の前に**対戦カード**の演出が出ます（約3秒）。右上から相手のカード（赤）、左下から自分のカード（青）がすべり込み、真ん中に「VS」が出ます。2台で同じ時刻に始まり、演出が終わってから試合が始まります（タップすると自分の画面の演出は閉じられますが、試合の開始は早まりません）
  - カードに出るもの：アイコン（称号の枠つき）・名前・称号・ランキングの順位とハイスコア（参加していない人はハイスコアだけ）・実績の数・オンライン対戦の勝敗。真ん中の下に、この相手との成績（「この相手に 3勝2敗」/「はじめての対戦」）
  - ランキングの順位は、最後にランキングを開いた・送ったときのもの（試合の前に通信で取りには行きません）
  - 相手は、端末ごとのランダムな番号から作った目印で見分けて、相手ごとの勝ち負けを記録します（番号そのものは送らず、画面にも出しません）
  - 写真アイコンは、設定の「オンライン対戦」→「相手に写真アイコンを見せる」（初めはオフ）をオンにした人だけ、小さくして（64×64）相手に送ります。オフのときは、相手の画面には名前の1文字目が出ます
  - **カードの色**：プロフィール画面の「対戦カード」で、自分のカードの見本を見ながら、色を「いつもの色」か**持っている背景**（解放した背景）から選べます。選んだ背景の絵がカードの下地になり、相手の画面にもその色で出ます（自分か相手かは、枠と「あなた／相手」の札の色で分かります）。あいさつ（hello）の profile に背景の id（`card`）を入れて送り、受け取った側は config.js にある id だけ使います。選んでいた背景が使えなくなったとき（実績のリセットなど）は、いつもの色に戻ります。保存先は `Save.data.cosmetics.cardBg`
  - 2戦目からは短い版（約1秒。「第2戦」と、この部屋での勝敗）
  - 端末の「視差効果を減らす」がオンのときは、動きをやめてフェードだけにします
  - 秒数は `config.js` の `online`（`introSlide`・`introTime`・`introExit`・`rematchIntroTime`・`introLead`）で変えられます
  - 古いバージョンの相手とは、演出なし（今までどおり、すぐに始まる）

- まず2台を**直接**つなぎます（PeerJS / WebRTC）。Wi-Fi のルーターの設定などで直接つながらないときは、6秒ほどで**公開のメッセージ中継サーバー（MQTT）経由**に自動で切りかえます。中継のときは、少し反応がゆっくりになります
- 中継サーバーは `config.js` の `online.relayBrokers` で変えられます（EMQX・HiveMQ の無料公開サーバーを使用。保証はありません）
- **1手の制限時間**：オンライン対戦だけ、1手に制限時間があります（`config.js` の `online.turnTime`。初めは15秒。0 なら制限なし）。持っているキャラの横に残り時間の円と秒数が出て、時間切れになると、その場で自動で落ちます。時間を数えて落とすのはホスト（物理計算をしている側）で、ゲストの画面にはホストから残り時間を送って表示します。1人・ともだちと・CPU対戦には制限時間はありません（設定画面の「制限時間」はなくしました）
- 物理計算は部屋を作った側のスマホだけで行い、相手にはキャラの位置と角度を送っています（2台でズレないように）
- 試合中に通信が切れると「接続が切れました」と出てタイトルに戻ります。画面を消したり、ほかのアプリに切りかえたりしても切れます
- リザルト画面の「もう一度」は、**お互いが押したら**次の試合が始まります。押した側は「相手を待っています…」になり（もう一度押すと取り消し）、相手の画面には「〇〇さんが再戦を希望しています」と出ます。両方そろうと「再戦！」と出てから始まります。相手がタイトルに戻ったり通信が切れたりしたときは「相手が退出しました」と出て、「もう一度」は押せなくなります（リザルト画面には残ります）
- **相手に伝わる情報**：名前・称号・ハイスコア（ランキングに参加している人は順位も）・実績の数・オンライン対戦の勝敗・端末の目印（番号から作った値）。写真アイコンは、設定でオンにした人だけ
- 直接つながったときは、お互いのネット上の住所（IPアドレス）が相手の端末に伝わります。中継サーバー経由のときは、ゲームのデータ（キャラの位置・名前・対戦カードの情報）が中継サーバーを通ります。知っている人と遊んでください
- 直接つなぐときは、最初に相手を見つけるためだけに PeerJS の無料公開サーバー（0.peerjs.com）を使います

### スタンプ（オンライン対戦のリザルト画面）

オンライン対戦が終わると、リザルト画面の下に4つのスタンプが並びます。タップすると、相手の画面にもポンッと出ます（自分のスタンプは右、相手のスタンプは左）。

- 送ったあと 1.5 秒は、次のスタンプを送れません（連打防止）
- 相手がタイトルに戻ると「相手が退出しました」と出て、スタンプは送れなくなります
- スタンプは、プロフィール画面の「スタンプ」で変えられます。枠をタップして、**図鑑に登録したキャラ**から選びます（まだのキャラはシルエットで選べません）。
  何も選んでいない枠には、最初から使える初期スタンプ（`config.js` の `stamps.defaults`）が入ります
- 新しいキャラを追加すると、図鑑に登録されたあとで、自動でスタンプにも選べるようになります
- 相手に送るのはキャラの ID（例 `chara03`）だけです。画像はどちらのスマホにも入っているので、相手の図鑑にいないキャラでも表示されます
- スコアアタック・ともだちと・CPU対戦では出ません

### 挑戦状

スコアアタック・競技・特殊ルールのリザルト画面の「挑戦状を送る」で、友だちに挑戦状の URL を送れます。

- URL を開いた人には「〇〇さんからの挑戦状（1270点）」と出て、**同じ順番のキャラ**・同じルールで挑戦できます
- 終わると「勝ち！」「負け…」が出て、「挑戦状を送り返す」で自分のスコアを入れて送り返せます
- URL の形：`https://.../?seed=12345&mode=solo&rule=wind&score=1270&name=あき`
  （seed＝キャラの順番を決める番号、mode＝`solo`（フリー）か `comp`（競技）、rule＝特殊ルール、score＝スコア、name＝名前）。
  競技の挑戦状は `mode=comp` で、受け取った人も競技のルールで遊びます（競技に rule は付けません）。mode が無い・`solo` の古い URL は、今までどおりフリーです。
  値がおかしい URL は挑戦状として扱わず、ふつうに始めます
- スマホの共有メニュー（Web Share API）で送ります。使えないブラウザでは、URL とコピーボタンが出ます
- **キャラを追加・削除すると（★4のオーラ版を足したときも）、同じ seed でもキャラの順番が変わります**。古いバージョンで作った挑戦状は、新しいバージョンでは順番が合わなくなります（送った人と受け取った人のバージョンがそろっていれば同じ順番です）

### リザルトカード・フォトモード

- **リザルトカード**：リザルト画面の「結果を画像でシェア」で、名前・称号・スコア・積んだ数・高さ・モード・タワーの絵・ゲームの URL を1枚の画像にします。
  形は横長（1200×630）と縦長（1080×1350）から選べます。写真アイコンは、載せるかどうかを選べます（初めは載せない設定）
- **フォトモード**：ポーズ画面・リザルト画面の「📷 フォトモード」で、ボタンなどを消して背景とタワーだけを表示します。
  タワー全体が収まるように縮小され、指でドラッグ（移動）・ピンチ（拡大・縮小）して構図を決められます（パソコンはマウスのホイールで拡大）。
  フォトモードの間は、キャラの動きが止まります
- どちらも「シェア」「撮影」で画像を共有します。画像付きで共有できない端末では、画像を保存します

### 高さで変わる背景

タワーが高くなるほど、背景が 草原 → 空 → 雲の上 → 夕焼け → 宇宙 と変わり、新しい背景に届くと「雲の上に到達！」と出ます。
地上の見た目は、プロフィールで選んだ背景（実績で解放するもの）です。区切りの高さと色は `config.js` の `sky` で変えられます（下記）。

### キャラのレア度

キャラにはノーマル（★）・レア（★★）・めっちゃレア（★★★）・激レア（★★★★）があり、レアほど出にくくなっています。
レア以上が出ると「レア！」「めっちゃレア！！」と表示され、キャラが光ります。
激レアは、今いるキャラが**オーラ**（光・闇）をまとった特別版です。出ると「激レア！！！」と画面が光り、専用の音が鳴ります。

積んだあとも、レア度ごとのオーラが残ります（★2：うすい色のふち／★3：ふち＋ときどきキラッ／★4：控えめなオーラ／★5：後光・虹色の光・虹の輪で、積んだあともはっきり光る）。
★5（まぼろし）は、着地した瞬間に虹色の光がはじけて、虹の輪が何重にも広がります（`js/aura.js` の `MYTHIC`。数や色はそこで変えられます）。持っている間・落ちている間は強く光ります。図鑑の激レアのカードでも、オーラが動いて見えます。

### 背景・土台

実績を達成すると、新しい背景（夕焼け・さくら・星空・銀河・ふしぎの国・オーロラ）や土台（石・氷・金・ダイヤ・鉄骨・ダンボール）が解放され、プロフィール画面で選べます。
銀河は「宇宙到達」（高さ9m）、ダイヤの台は「無敗の王」（CPU「つよい」に3連勝）で解放される、むずかしいものです。オーロラの解放のしかたは、ひみつです。
オーロラの空には、緑・水色・紫の光の帯がゆらめきます。ダンボールの台は、隠し実績のごほうびです。

### 実績

実績は全48個で、分類（かんたん・積む・高さ・スコア・特殊ルール・対戦・CPU・オンライン・レア・図鑑・累計・隠し・イベント）ごとに並びます。
「はじめの一歩」「初勝利」はすぐ取れますが、ほかはむずかしめです。
合計の回数や数を数える実績には、進み具合のバー（例 347 / 1000）が出ます。
隠し実績は、達成するまで名前・説明・称号が「？？？」になっています。
実績によっては、称号のほかに背景・土台ももらえます（実績画面の「＋ 背景『オーロラ』」など）。

- 設定画面の「ランキングへの参加」で「同意を取り消す」を押すと、ランキング（フリー・競技の両方）から自分の記録を消し、参加をやめます。次にスコアアタック・競技を遊ぶときに、また同意のダイアログが出ます

## 2. キャラの追加方法

1. **画像を用意する**
   背景を透過した画像（PNG または WebP）。余白は自動で無視されます。
   長い辺が 500px 前後だと、きれいに表示されて読み込みも軽くなります。
2. **`images/` フォルダに入れる**
   ファイル名は**半角の英数字と小文字**にします（例：`chara13.png`）。
   公開先（GitHub Pages）は大文字と小文字を区別するので、`Chara13.PNG` のように書くと、
   パソコンでは動いても公開先で読み込めなくなります。
3. **`characters.js` に1行足す**

   ```js
   window.CHARACTERS = [
     { file: "images/chara01.webp", name: "直立", description: "…" },
     ...
     { file: "images/chara13.png", name: "新しいポーズ", description: "図鑑に出る説明文" },  // ← これを足す
   ];
   ```

   | 項目 | 内容 |
   | --- | --- |
   | file | 画像の場所（`images/` から書く） |
   | name | キャラの名前 |
   | description | 図鑑に出る説明文（省略可） |
   | rarity | レア度。`"N"`（ノーマル）/ `"R"`（レア）/ `"SR"`（めっちゃレア）/ `"UR"`（激レア）/ `"MR"`（まぼろし）。省略すると `"N"` |
   | weight | 同じレア度の中での出やすさの割合（省略可）。省略すると 1（同じレア度のキャラで等分）。2 にすると、ほかの2倍出る。0 にすると出なくなる。レア度ごとの出現率は config.js の `rarity` の `rate`（%） |
   | id | キャラの ID（省略可）。省略すると画像のファイル名から作られる（`images/chara13.png` → `chara13`）。図鑑・スタンプ・オンライン対戦は、この ID でキャラを見分ける。**一度公開したら変えない**（変えると、図鑑の登録が外れる） |
   | size | 画面での大きさ（長い辺の長さ。省略すると 130） |

4. **当たり判定を確認する**
   `hitbox.html` を開くと、全キャラの「本当の輪郭（赤）」と「当たり判定（緑）」が重ねて表示されます。
   緑が赤にほぼ沿っていればOKです。

5. **（必要なら）当たり判定を調整する**

   | 項目 | 使いどころ |
   | --- | --- |
   | `tolerance: 0.5` | 形がズレている → 小さくすると忠実になる（初期値 0.8） |
   | `smooth: 4` | 置いたあとグラグラ揺れ続ける → 指先などの細い出っぱりを削る（3〜5くらい） |
   | `feet: 0.08` | 立たせるとグラつく → 足の裏を平らにする範囲を広げる（初期値 0.05、0 で平らにしない。前の書き方 `base: 0.08` も使える） |
   | `hull: true` | それでも安定しない → 輪郭を包む1つの形にする（一番安定。足の間のすき間も埋まる） |

   例：`{ file: "images/chara10.webp", name: "ポーズ10", tolerance: 2, smooth: 4 },`

新しいキャラは、図鑑にも自動で並びます。キャラは**一番下に足して**ください（図鑑の番号がずれないように）。

### 出現率（レア度ごと）

config.js の `rarity` の `rate` に、**レア度ごとの出現率（%）**を書きます。同じレア度のキャラで分け合います（characters.js の `weight` で、レア度の中の割合を変えられる）。

| レア度 | rate（今の値） | キャラ | 1体あたり |
| --- | --- | --- | --- |
| ★ ふつう（N） | 76.5% | 7体 | 約10.9% |
| ★★ レア（R） | 15% | 3体 | 5% |
| ★★★ めっちゃレア（SR） | 5% | 5体（サイズ違い3体をふくむ） | 1% |
| ★★★★ みたことない（UR） | 2.5% | 4体 | 約0.63% |
| ★★★★★ まぼろし（MR） | 1% | 3体 | 約0.33% |

- 実際には「同じキャラが2回続けて出ない」決まりがあるので、よく出る「ふつう」は少しだけ減り、ほかのレア度が少しだけ増えます
- **出現率のテスト**：管理者モードの「出現率のテスト」で、今の設定で好きな回数（初めは1万回）抽選した実際の回数と、設定との差を、レア度ごと・キャラごとに表で見られます（公開版では、管理者モードを開かないと出ません）

### ★5（まぼろし）

とても出にくいキャラ（初めは3体で 0.5%、1体あたり約0.17%）。出ると、画面が虹色に光り、「まぼろし！！！」の虹色の文字と、専用の効果音（config.js の `sounds.legendary`。空なら仮の音）の、いちばん豪華な演出になります。
図鑑では虹色の専用の枠で、まだ見つけていないまぼろしは、シルエットではなく「？」で並びます。

- 今のまぼろし：スマホ自慢（chara13）・白シャツの伊達男（chara14）・キャプテン（chara15）。名前と説明文は仮です
- 画像の元は `_source/images/` の PNG で、周りの透明を切って、高さ 524px の WebP にしたものを `images/` に置いています（キャプテンの画像は背景が白かったので、外側の白を透明にしました）
- 管理者モードの「次に出すキャラ」で、まぼろしも出せます（演出の確認用）

### ★3 サイズ違い（ビッグ〇〇・ミニ〇〇）

今いるキャラの画像を、大きく・小さくした別のキャラです。**新しい画像はいりません**。見た目と当たり判定を同じ倍率で大きく・小さくします。

```js
{ id: "chara05_big", base: "images/chara05.webp", name: "ビッグ台湾案内人", rarity: "SR", variant: "big", description: "図鑑に出る説明文" },
```

- `variant`：`"big"`（大きい）/ `"small"`（小さい）。倍率は config.js の `sizeVariants`（初めは大 1.5倍・小 0.6倍）
- 大きくしすぎて土台からはみ出さないよう、画像の長い方の辺が `sizeVariants.maxSize`（初めは 200。土台の幅は 280）より大きくならないように倍率を下げます
- 当たり判定の設定（tolerance など）は、元のキャラのものを使います
- 図鑑では元のキャラとは別の枠で、「BIG」「MINI」の札が付きます
- 今のサイズ違い：ミニ床アレルギー（v2.0.0 までの古い保存データの "chara10" の図鑑・スタンプは、保存データを開いたときに "chara10_small" に直す。標準の大きさの ★1「床アレルギー」（"chara10"）は v2.1.0 で戻した）・ビッグブンリキエイリアン（大きくて立てるとぐらぐら）・ビッグ台湾案内人（大きくて細長い。寝かせるのがコツ）

### ★4（激レア）を足す

今いるキャラの画像に、オーラをまとわせた別のキャラを作ります。**新しい画像はいりません**。

```js
{ id: "chara03_light", base: "images/chara03.webp", name: "光の体育座り", rarity: "UR", aura: "light", description: "図鑑に出る説明文" },
```

| 項目 | 内容 |
| --- | --- |
| id | **必ず書く**。ほかのキャラと重ならない名前（半角英数字と `_`）。同じ画像の元のキャラと見分けるために使う |
| base | 使う画像の場所（元のキャラと同じ画像）。`base` を書いたときは `file` は書かない |
| rarity | `"UR"` |
| aura | オーラの種類。`"light"`（光：白〜金の光が広がり、光の粒が昇る）／`"dark"`（闇：紫〜黒のもやが立ちのぼり、ときどき稲妻が走る） |

- 当たり判定は、元のキャラと同じ形です（オーラは見た目だけ）
- 図鑑には別のキャラとして並び、図鑑コンプリートの数にも入ります
- オーラの種類を増やすときは、`js/aura.js` の `TYPES` に1つ足します（光の色・広がり方・粒・稲妻を書く。書き方はファイルの先頭に説明あり）

## 3. お知らせ・ランキングの更新方法

`data/` フォルダの JSON ファイルを書きかえて GitHub に上げると、遊んでいる人の画面に反映されます。
（古い内容がキャッシュに残って表示されないよう、毎回最新のファイルを読み込むようにしてあります）

### JSON を書くときの注意

- 文字は `"`（半角のダブルクォーテーション）で囲む
- 項目と項目の間は `,`（カンマ）で区切る。**最後の項目の後ろにはカンマを付けない**
- 本文の中で改行したいときは `\n` と書く
- 書き間違えると読み込めなくなり、画面に「取得できません」と出る。
  うまくいかないときは「JSON チェック」で検索して出てくる確認サイトに貼り付けると、間違いの場所がわかる

### お知らせ（`data/news.json`）

```json
{
  "news": [
    {
      "id": 2,
      "date": "2026-11-01",
      "type": "event",
      "title": "ランキング開始！",
      "body": "ハイスコアランキングを始めました。\nタイトル画面の「ランキング」から見られます。"
    },
    {
      "id": 1,
      "date": "2026-10-26",
      "type": "update",
      "title": "かじわらタワーバトル 公開しました",
      "body": "キャラを積み上げて、落とした方が負けのバランスゲームです。"
    }
  ]
}
```

| 項目 | 内容 |
| --- | --- |
| id | 番号。**新しいお知らせほど大きい数にする**（前より大きい id があると「未読」になり、赤い点とポップアップが出る） |
| date | 日付（`年-月-日`）。新しい順に並ぶ |
| type | `"update"`（アップデート）または `"event"`（イベント） |
| title | タイトル |
| body | 本文 |

新しいお知らせは、`"news": [` のすぐ下（先頭）に足すと分かりやすいです。

### ランキング（オンライン）：Google スプレッドシートで自動集計

スコアアタック（フリー）と競技のハイスコアを自動で集めて、ランキングに表示します（特殊ルールは載せません）。

**フリーと競技**：ランキング画面の上のタブで「フリー」「🏁 競技」を切りかえます。

- フリー ＝ 今までのランキング（スコアアタックのふつうのルール）。シート「ranking」。今までの記録はそのまま
- 競技 ＝ 競技モードのランキング。シート「ranking_comp」（新しい `ranking.gs` が、最初に読み書きしたときに自動で作る。列はフリーと同じで、hidden の列もある）
- ゲームが送るデータに `mode`（`"free"` / `"comp"`）が付きます。mode が無い（古いバージョンのゲーム）ときは、フリーとして扱います
- 競技のスコアも「積んだ数 × `COMP_PER_PIECE` ＋ 高さ × `COMP_PER_METER`」と合うかを確かめます
- 画面の下の「あなたのハイスコア」は、選んでいるタブのものです
- ランキングへの参加の同意は、フリー・競技で共通です（スコアアタック・競技を初めて遊ぶときに同意してもらう。上の「タイトル画面のメニュー」の下の説明）
- **記録を消す**：ゲームの設定画面で「同意を取り消す」を押すと、ゲームが `{ action: "delete", id }` を送り、`ranking.gs` がその端末の番号の行を、フリー・競技の両方のシートから消します（返事は `{ ok: true, action: "delete", deleted: 消した行の数 }`）。古い `ranking.gs` のままでは消せないので、ゲームは「消せませんでした」と出して、同意はそのままにします
- ゲームは、サーバーが競技に対応している（`?mode=comp` に `mode: "comp"` が返る）と分かってから、競技のスコアを送ります。古い `ranking.gs` のままのあいだは、競技のタブに「準備中」と出て、競技のスコアは送りません（フリーに混ざらないように）。新しい `ranking.gs` をデプロイすると、ゲームを開き直さなくても、次に送るときから競技も載ります
`config.js` の `ranking.url` が `""` のあいだは、下の `data/ranking.json`（手で書く）のランキングが出ます。

**始め方（最初に1回だけ）**

1. Google ドライブで、新しい**スプレッドシート**を作る（名前は自由。例：「タワーバトル ランキング」）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から書いてある `function myFunction() {...}` を消して、このフォルダの `server/ranking.gs` の中身を**全部**貼り付け、保存（💾）
4. 右上の「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」を選び、
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   にして「デプロイ」。Google アカウントの許可を求められたら許可する
   （「このアプリは確認されていません」と出たら「詳細」→「〇〇（安全ではないページ）に移動」）
5. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/.../exec`）をコピーし、`config.js` の `ranking.url` に貼る
6. バージョン番号を上げて公開する（「更新を公開する」）

最初のスコアが届くと、スプレッドシートに「ranking」というシートが自動でできます。

**ランキングの管理**

| 列 | 内容 |
| --- | --- |
| id | 端末ごとのランダムな番号（画面には出ない） |
| name / score / count / height / date | 名前・スコア・積んだ数・高さ・記録した日（1人1行。一番いいスコアだけ残る） |
| hidden | **何か書く（例：`x`）と、その人はランキングから消える**。変な名前・ありえないスコア・ふさわしくない写真のとき用 |
| title | 称号 |
| icon | 写真アイコン（本人が載せると選んだときだけ。画像を文字にしたもの） |
| ach / achTotal | 実績の達成数 / 全部の数（ここから下は、本人が設定の「ランキング」→「プロフィールを公開」をオンにしたときだけ入る） |
| dex / dexTotal | 図鑑の登録数 / 全部の数 |
| bg / platform | 選んでいる背景・土台の id（`ranking.gs` の `BACKGROUNDS`・`PLATFORMS` にある id だけ保存する） |
| plays / pieces | プレイ回数・これまでに積んだ数の合計 |
| onlineWins / onlineLosses | オンライン対戦の勝ち・負け（遊んだことがある人だけ） |

- **ランキングの人のプロフィール**：ランキングの行を押すと、その人のプロフィールが出ます（アイコンと称号の枠・名前・称号・順位・ハイスコア・積んだ数・高さ・記録した日。自分の行には「あなた」と、自分のプロフィール画面へのボタン）。端末の番号（id）は出しません。手で書く `data/ranking.json` のときは、書いてある項目だけを出します
- **プロフィールの公開**：設定画面の「ランキング」→「プロフィールを公開」（初めはオフ。ランキングへの参加に同意しているときだけ選べる。同意してから初めてのゲームのあとにも、1回だけ聞く）をオンにした人だけ、上の ach〜onlineLosses も送り、プロフィールに実績・図鑑の数・プレイ回数・積んだ数の合計・オンライン対戦の勝敗と、背景・土台の見本が出ます。オフにすると、次に送ったときにシートから消えます。公開していない人・古いバージョンの人は、そこだけ出ません
- 届いた値は `ranking.gs` で確かめます（整数で範囲の中か・達成数が全部の数より多くないか・背景と土台の id が `BACKGROUNDS`・`PLATFORMS` にあるか）。おかしい値の欄は保存しません。**`config.js` の `themes` に背景・土台を足したときは、`ranking.gs` の `BACKGROUNDS`・`PLATFORMS` にも足して、新バージョンでデプロイしなおしてください**
- 前のバージョンで作ったシートでも、新しい `ranking.gs` で最初に読み書きしたときに、見出しの列が自動で足されます

- 行を消すと、その人の記録は消えます（また遊ぶと、次の自己ベストから載ります）。ずっと出したくない人は、行を消さずに hidden に書いてください
- ありえない値（スコアが「積んだ数・高さ」の計算と合わないなど）は受け付けませんが、本気でズルをする人は防げません。気になる記録は hidden で隠してください
- ランキングに参加した人のうち写真アイコンがある人には、写真も載せるかを別に1回だけ聞きます（設定画面の「ランキング」→「写真アイコンを載せる」でいつでも変えられます）。
  名前・称号・写真を変えると、次にアプリを開いたとき・ゲームのあと・ランキングを開いたときに反映されます
- `server/ranking.gs` を書きかえたときは、次の手順で更新します（こうすると URL が変わりません。「新しいデプロイ」にすると URL が変わってしまう）
  1. スプレッドシートの「拡張機能」→「Apps Script」を開く
  2. 中身を全部消して、新しい `server/ranking.gs` の中身を全部貼り付けて、保存（💾）
  3. 右上の「デプロイ」→「デプロイを管理」→ 今のデプロイの鉛筆マーク（編集）
  4. 「バージョン」を「**新バージョン**」にして「デプロイ」
- `config.js` の `score`（配点）を変えたときは、`server/ranking.gs` の `PER_PIECE`・`PER_METER` も同じ数にする（競技の `competitive` の配点は `COMP_PER_PIECE`・`COMP_PER_METER`）

### ランキング（手で書く：`data/ranking.json`）

`config.js` の `ranking.url` が `""` のときに表示されます。今は中身が空です（画面には「ランキングは準備中です」と出ます）。
手で書くときは、次のように書きます。

```json
{
  "updated": "2026-11-01 18:00",
  "ranking": [
    { "rank": 1, "name": "たろう", "score": 2450, "count": 18, "height": 6.5, "date": "2026-10-31" },
    { "rank": 2, "name": "はなこ", "score": 2180, "count": 16, "height": 5.8, "date": "2026-10-30" },
    { "rank": 3, "name": "じろう", "score": 1920, "count": 14, "height": 5.2, "date": "2026-11-01" }
  ]
}
```

| 項目 | 内容 |
| --- | --- |
| updated | 更新日時（画面に「〇〇 更新」と出る） |
| rank | 順位（1〜3位は金・銀・銅で表示） |
| name | 名前 |
| score | スコア |
| count | 積んだ数 |
| height | 高さ（m） |
| date | 記録した日 |
| title | 称号（省略可）。**`"developer"` と書いた人には、開発者専用のコード風の枠と札**が出ます（下の「称号の飾り」） |

- **rank は省略できます**。書いていなければ、ファイルに書いた並び順で 1位・2位… と決まります
- **1〜3位には、アイコンの上に金・銀・銅の王冠**が出ます（順位から自動で決まる）
- **部門ごとのランキング**：`"ranking"` の代わりに `"divisions"` を書くと、部門ごとに見出しをつけて並べ、部門ごとに上位3人に王冠を出します

```json
{
  "updated": "2026-11-01 18:00",
  "divisions": [
    { "name": "スコアアタック", "ranking": [ { "name": "かじわら", "title": "developer", "score": 5000 }, { "name": "たろう", "score": 3000 } ] },
    { "name": "特殊ルール「風」", "ranking": [ { "name": "はなこ", "score": 2000 } ] }
  ]
}
```

- 開発者の印は、この手で書く `data/ranking.json` のときだけ出ます。オンラインのランキング（ゲームから送られてくる称号）では、「developer」「開発者」と送られてきても出しません（ゲームの中から、ほかの人が開発者の印を付けることはできません）

準備中に戻すときは、`"ranking": []` と空にします。

### 実績（`data/achievements.json`）

実績の条件と、もらえる称号を書きます。

```json
{
  "achievements": [
    {
      "id": "stack10",
      "name": "10体積み",
      "title": "積み上げ名人",
      "description": "1回のゲームで10体積んだ",
      "category": "積む",
      "condition": { "type": "count", "value": 10 }
    },
    {
      "id": "edge_landing",
      "name": "崖っぷち",
      "title": "綱渡り",
      "description": "土台の端ギリギリ（端から5%以内）に着地させて、積めた",
      "category": "隠し",
      "hidden": true,
      "condition": { "type": "edgeLanding", "ratio": 0.05 }
    }
  ]
}
```

- `id` は半角英数字。**一度公開したら変えない**（変えると、達成済みの人も未達成に戻る）
- `category`：実績画面の分類（見出し）。同じ分類の実績がまとまって並ぶ（json に書いた順）
- `hidden`：`true` にすると隠し実績になる（達成するまで名前・説明・称号・ごほうびが「？？？」）
- `reward`（省略可）：称号のほかにもらえる背景・土台。`{ "background": "背景の id" }` か `{ "platform": "土台の id" }`。
  その背景・土台は、`config.js` の `themes` に **`unlock: "achievement"`** と書いて足します（見た目の色・描き方は config.js、どの実績で解放されるかは achievements.json）。
  実績画面には「称号『〇〇』＋ 背景『〇〇』」と出て、背景・土台を選ぶ画面には「実績『〇〇』を達成」（隠し実績なら「隠し実績を達成」）と出ます。
  前からある `unlock: "実績の id"`（config.js 側に書く方法）も、そのまま使えます

  ```json
  { "id": "size_all", "name": "伸び縮み自在", "title": "サイズマスター", "rank": "gold", "reward": { "background": "wonderland" }, "condition": { "type": "dexAll", "variant": true } }
  ```
- `rank`：称号の枠の種類。その称号を選ぶと、アイコンのまわりと称号の札に枠が付く（`js/frames.js`・`css/style.css` の「称号の枠」）

  枠の形は、どの格も同じ（同じ太さの輪＋ふちに並ぶ星）。違うのは色と、星の数だけです。星は丸いアイコンのふちに沿って、円のてっぺんから左右に等間隔で並び、数が増えるほど小さく・間を詰めて重ならないようにしています（`js/frames.js` の `STAR_LAYOUT`。CSS の `.stars-〇` の数値もこの表から計算したもの）（星の数は `js/frames.js` の `STARS`。アイコンに `stars-〇` のクラスが付く。リザルトカードの画像も同じ数）。称号の札も、形は同じで色だけが変わります（札には星を付けません）。

  | rank | 色 | 枠の星 |
  | --- | --- | --- |
  | `bronze` | 銅色 | ★ |
  | `silver` | 銀色 | ★★ |
  | `gold` | 金色（ときどき光が走る） | ★★★ |
  | `legend` | 虹色（輪がゆっくり回る・札の色が流れる） | ★★★★ |
  | `mythic` | まぼろし：虹と白の輪が回り、まわりが白く光る・札は夜空色に色が流れる | ★★★★★ |
  | `event` | オレンジ×紫（期間限定の実績） | ★★★ |
  | `secret` | 隠し：紫×黒（隠し実績。`"decoration": "question"` で、ふちに星の代わりに「？」） | ？？？ |

  - 色は `css/style.css` の「格ごとの色」で、CSS の変数（`--frame-color`・`--frame-dark`・`--frame-light`・`--frame-text` など）を切りかえています。形の CSS は1か所（`.avatar.frame`・`.title-badge.ranked`）だけ。**新しい格を足すときは、「格ごとの色」に1行足し**、`js/frames.js` の `RANKS` と `js/card.js` の `FRAME_COLORS`（リザルトカードの画像用）にも同じ色を足します
  - 枠の太さ・星の大きさは、アイコンの大きさ（`--av`）に合わせて変わります（小さなアイコンでも、プロフィールの大きなアイコンでも同じ形）
  - 枠が出る場所：タイトル画面左上・プロフィール画面・称号を選ぶ画面・リザルト・オンライン対戦の相手（相手にも rank を送る）・ランキング（称号の文字から実績を探して決める）・リザルトカードの画像
  - 称号を選んでいないとき・rank が無いときは枠なし。動く枠（金の光・虹）は「視差効果を減らす」設定では止まります

  **称号を選ぶ画面**：プロフィール画面の「称号」の欄（今のアイコン＋枠＋称号の札）を押すと開きます。
  - 上に、今選んでいる称号の大きな見本（自分のアイコン＋枠＋名前＋称号の札）
  - その下に「称号なし（枠なし）」と、格ごとの見出し（まぼろし・レジェンド・ゴールド・シルバー・ブロンズ・期間限定・隠し。取った数 / 全部の数）で分けた称号。1つずつ、自分のアイコンに枠を付けた見本と称号の札が出ます
  - タップすると上の見本が変わり、「これにする」で決定、「もどる」で変えずに戻ります。選んでいるものには ✓
  - まだ取っていない称号は、枠が灰色・称号が「？？？」（枠の星の数で格は分かる）で、下に取り方（実績の説明）が出ます。隠し実績は取り方も「？？？」、期間が終わったものは「期間限定（終了）」
  - 選んだ称号の保存のしかた（`Save.data.profile.titleId`）は前と同じです
- `condition` の `type` に使えるもの：

| type | 条件 |
| --- | --- |
| `count` | 1回のゲームで value 体積んだ（対戦は2人の合計） |
| `ownCount` | 1回のゲームで、自分が value 体積んだ（対戦では、自分が落として積めた数だけ。オンラインは自分の側、ともだち・CPU はプレイヤー1。ひとりモードは `count` と同じ） |
| `height` | 1回のゲームで高さが value m に届いた |
| `score` | ひとりモードで value 点以上（スコアアタックのふつう・特殊ルール（期間限定もふくむ）・競技のどれでも。対戦は数えない） |
| `plays` | 合計 value 回遊んだ（全部のモードの合計） |
| `totalPieces` | これまでに合計 value 体積んだ |
| `versusWins` | 2人対戦でプレイヤー1（プロフィールの人）が value 回勝った |
| `dexCount` | 図鑑に value 体登録した |
| `dexComplete` | 図鑑を全部登録した（value は不要） |
| `onlineWins` | オンライン対戦で value 回勝った |
| `cpuWins` | CPU（`level` の強さ。`"easy"`・`"normal"`・`"hard"`）に value 回勝った |
| `cpuStreak` | CPU（`level` の強さ）に value 連勝した（負けると連勝は0に戻る） |
| `ruleScore` | 特殊ルール `rule`（例 `"wind"`）で value 点以上。`"all"` なら全部のルールで value 点以上 |
| `rarityPlaced` | レア度 `rarity`（例 `"SR"`）のキャラを、合計 value 体積んだ（value を省略すると1） |
| `auraPlaced` | `auras`（例 `["light", "dark"]`）に書いたオーラの★4を、全部の種類1体以上積んだ |
| `noRotate` | スコアアタック・特殊ルールの1回のゲームで、回転を使わずに value 体積んだ |
| `quickStreak` | スコアアタック・特殊ルールの1回のゲームで、1手 `seconds` 秒以内で value 体続けて積んだ |
| `edgeLanding` | 土台の端から `ratio`（土台の幅に対する割合。0.05 なら5%）以内の所に着地させて、積めた |
| `eventWins` | イベント `event`（例 `"halloween2026"`）のステージで value 回勝った |
| `flipPlaced` | 1回のゲームで、反転したキャラを value 体積んだ |
| `noRotateFlip` | スコアアタック・特殊ルールの1回のゲームで、回転も反転も使わずに value 体積んだ |
| `afterBig` | ビッグのキャラを積んだあと、同じゲームでさらに value 体積んだ |
| `buzzerBeater` | オンライン対戦で、制限時間の残り `seconds` 秒以内に自分で落として、積めた（時間切れで自動で落ちたものは数えない） |
| `challengeWins` | 挑戦状で、相手のスコアを上回った回数が value 回 |
| `stampsSent` | オンライン対戦のリザルトで、スタンプを value 回送った |
| `rarityDrawn` | レア度 `rarity` のキャラが、自分の番に value 回出た（積めなくてもよい。CPU・相手の番はのぞく） |
| `dexAll` | 条件に合うキャラを全部図鑑に登録した。`"rarity": "MR"`（そのレア度）・`"variant": true`（サイズ違い）。期間限定のキャラはのぞく |
| `fallFirst` | スコアアタック・特殊ルールで、1体目で落とした |
| `dejaVu` | 1回のゲームで、同じキャラが1体おきに3回出た（A→？→A→？→A） |
| `flipStreak` | 1体を落とす前に、反転を value 回続けて押した（回転・落とすで数えなおし） |
| `exactHeight` | タワーの高さが、ちょうど value m（小数2けた。画面の表示と同じ）のときに積めた |

- 判定は今までと同じく、1体積むたびと、ゲームが終わったときに1回ずつです。新しい条件は、ゲーム中に数を数えておくだけなので、重くなりません
- 管理者モードの自由配置モードでは、判定しません

### 実績のリセット（`config.js` の `achievementsEpoch`）

実績を大きく作り直したときに、**全員の実績を一度だけリセット**するための番号です（今は `2`）。

- 番号を1つ上げて公開すると、ゲームを開いたときに、セーブデータの番号が古い人だけ、1回だけ次のことが起きます
  - 実績・戦績（プレイ回数・ハイスコア・勝利数・合計の数など）を初期に戻す
  - 称号を外し、背景・土台を最初のもの（青空・木の台）に戻す
  - 次にタイトル画面が出たとき「アップデートで実績が新しくなったため、実績と戦績をリセットしました」と1回だけ出す
- **図鑑・名前・写真・設定・スタンプは消えません**
- 戦績も戻すのは、「合計100回」などの累計の実績が、リセットした直後にまた解除されないようにするためです
  （図鑑は残るので、「図鑑 半分」など図鑑の実績は、開いたときにまた解除されます）
- 古い番号のバックアップファイルを読み込んだときも、同じリセットが起きます（前の実績は戻りません）
- **開いた人から順に**反映されます。しばらく開いていない人は、次に開いたときにリセットされます
- もう一度リセットしたいときは、また番号を1つ上げます。下げてはいけません（下げても何も起きません）
- ランキングに載っているハイスコアは消えません（ランキングのシートは別なので、消したいときはシートで消す）

### 期間限定イベント（`data/events.json`）

お知らせと合わせて、期間中だけ遊べる特殊ルールや、期間中だけ出るキャラ、イベントのステージを用意できます。
今は「ハロウィンイベント」（`halloween2026`・2026/10/28 12:35〜11/3）が入っています（下の「ハロウィンイベントの作り」）。

**1. イベントを書く**（`data/events.json`）

```json
{
  "events": [
    {
      "id": "halloween2026",
      "name": "ハロウィンイベント",
      "start": "2026-10-25",
      "end": "2026-10-31",
      "description": "おばけの特殊ルールと、限定キャラが登場！"
    }
  ]
}
```

| 項目 | 内容 |
| --- | --- |
| id | イベントの名前（半角英数字）。ルールやキャラの `event` に同じものを書く |
| name / description | イベントの名前と説明（メモ。今は画面には出ない） |
| start | 始まる日（`年-月-日`。時刻も決めたいときは `"2026-10-25 18:00"`） |
| end | 終わる日。**その日の終わりまで**開催（時刻を書いたときは、その時刻まで） |

日時は、遊んでいる人のスマホの時計で判定します。

**2. 期間限定にするものに `event` を書く**

- 特殊ルール：`config.js` の `rules` に `event: "halloween2026"` を足す（動きは「特殊ルールを追加する」と同じく `js/rules.js` に書く）。
  期間中だけ、モード選択の「ひとりで」から開く画面の特殊ルールの一覧に「期間限定」の札つきで出ます
- キャラ：`characters.js` の行に `event: "halloween2026"` を足す。期間中だけ落ちてきます。
  図鑑には、期間中か、一度積んだことがあるときだけ並びます（図鑑コンプリートの数には入りません）。
  限定キャラは `characters.js` の**一番下**に足してください（図鑑の番号がずれないように）

**3. お知らせを出す**：`data/news.json` に `"type": "event"` のお知らせを足します。

※ 終わったイベントは、`events.json` に**残しておいてください**（実績画面で「期間限定（終了）」と出したり、背景・土台の解放条件の説明にイベント名を出したりするのに使います）。期間外なら何も起きません。

### 称号の飾り（アイコンのふちに並ぶもの）

アイコンのふちに並ぶ飾り（星の数は称号の格で決まる）は、**称号ごとに種類を決めます**。`data/achievements.json` の実績に `"decoration"` を書きます（書いていなければ星）。
タイトル画面・プロフィール・称号を選ぶ画面・リザルト・ランキング・オンライン対戦のカード・リザルトカードの画像のすべてで、同じ飾りになります。

```json
{ "id": "pumpkin_king", "title": "パンプキング", "rank": "event", "decoration": "pumpkin", … }
```

| decoration | 飾り |
| --- | --- |
| （書かない） / `"star"` | 星（枠の色） |
| `"pumpkin"` | カボチャ（`images/decorations/pumpkin.svg`）。今は「パンプキング」の称号だけ |
| `"snow"` | 雪の結晶（`images/decorations/snowflake.svg`）。今は使っている称号なし |
| `"question"` | 「？」（`images/decorations/question.svg`）。隠しの格（`secret`）の称号 |

- 飾りは、星と同じ場所・同じ数に並びます（`js/frames.js` の `STAR_LAYOUT`）
- 称号を選ぶ画面では、まだ取っていない称号も、灰色にした飾りで見本が出ます
- **飾りを足すとき**：画像を `images/decorations/` に置き（正方形・透明の背景。svg か 128×128 くらいの png）、`js/frames.js` の `DECORATIONS` と、`css/style.css` の「称号の飾り」（`.deco-〇〇 { --deco-img: url(…) }`）に1行ずつ足して、実績に `"decoration": "〇〇"` を書きます

**開発者の枠**：称号「開発者」には、星やカボチャではなく、専用の「コード風」の枠が付きます（黒っぽい輪に緑に光るふち、ふちに沿って `</>` と 0・1 が並び、ゆっくり回りながら光が流れる。「視差効果を減らす」では動かない）。称号の札も、黒地に緑の等幅の文字と点滅するカーソルの、コード風の札です。

- 開発者の枠と札が出るのは、**管理者モードの端末**で称号「開発者」を選んだときと、**手で書く `data/ranking.json` の `"title": "developer"`** の人だけです
- ほかのプレイヤーは、選ぶことも取ることもできません。オンライン対戦の相手やオンラインのランキングで「開発者」と名乗られても、開発者の枠にはなりません

| `data/achievements.json` | 実績「かぼちゃの王」（`eventWins` で3勝・`"event": "halloween2026"` で期間限定） |
| `js/rules.js` の `haunted` | 暗闇・稲妻・おばけの動き。おばけの押す動きは `simulate` で CPU の試算にも入る |
| `js/halloween.js` | モード選択画面のボタン・ステージの説明とごほうびの画面・リザルトの「ごほうびゲット！」・タイトルのかぼちゃとこうもり |
| `js/halloween-home.js` | 期間中のホーム画面の後ろの絵の飾り（丘・おばけ屋敷・ジャック・オ・ランタン・霧・おばけ） |
| `data/news.json` | イベントのお知らせ（`"type": "event"`） |

- **期間中のホーム（タイトル）画面**：プロフィールで何を選んでいても、まだ解放していなくても、後ろの絵を背景「ハロウィンの夜」・土台「かぼちゃの台」で描きます（ごほうびの予告）。さらに、丘の上の光るジャック・オ・ランタン（光がゆらゆら）・おばけ屋敷のシルエット（窓がまたたく）・地面の近くを流れる霧・ときどき出て消える小さなおばけを足します
  - 変わるのはホーム画面の見た目だけです。ほかの画面・ゲーム中は選んだ背景・土台のままで、選んだもの・解放の状態も変わりません
  - 地面はスタートボタンの裏に隠れるので、かぼちゃと屋敷は塔の左右の丘の上に置いています
  - ロゴ横のかぼちゃ・CSS のこうもり（3匹）はそのまま。キャンバスのこうもりはホームでは3匹に減らし、鳥は出しません
  - 数・速さは `config.js` の `events.halloween2026.home`（`pumpkins`・`flicker`・`windowBlink`・`fog`・`ghosts`・`bats`）。端末の「視差効果を減らす」が ON のときは、霧・おばけ・光の揺れを止めます
  - 丘・屋敷・かぼちゃ・霧・おばけの絵は最初に1回だけ作り、毎フレームは貼るだけです
- 勝利数は `Save.data.eventStats.halloween2026`（`{ wins, losses }`）に保存され、バックアップにも入ります。負けても減りません
- イベントの勝ち負けは、ふつうの CPU 対戦の戦績・勝利数の実績には数えません（戦績画面の「イベント」に別に出ます）
- もらった背景・土台・実績は、イベントが終わっても使えます（勝利数で決まるため）
- 期間限定の実績（`"event"` を書いた実績）は、期間外で未達成なら「期間限定（終了）」と表示し、全体の達成数に数えません
- **確認するとき**：管理者モードの「イベント期間中として表示」を ON にすると、日付に関係なくイベントが出ます。「ハロウィンの勝利数」で 0〜3 勝に変えて、ごほうびを確かめられます

**次のイベントを作るとき**は、`events.json` にイベントを足し、`config.js` の `events`・`rules`（`stage: true`）・`cpu`（`event`）・`themes`（`unlock: { event, wins }`）を同じように書きます。
ボタンや説明の画面は `js/halloween.js` をまねて作ります。

### 背景・土台を追加する

`config.js` の `themes` に1行足します。`unlock` には、解放条件にする実績の id（`data/achievements.json`）を書きます。
`null` なら最初から使えます。
`"achievement"` と書くと、`data/achievements.json` の実績の `reward` で解放されます（どの実績のごほうびかを、実績の方に書く）。

```js
backgrounds: [
  ...
  { id: "ocean", name: "海", unlock: "total100", top: "#2a9df4", bottom: "#bfe9ff", cloud: "#ffffff", ground: "#e8d29a", groundDark: "#cdb57a" },
],
platforms: [
  ...
  { id: "candy", name: "おかしの台", unlock: "score1000", style: "crystal", body: "#ff8fb8", top: "#fff0f6", pillar: "#e07aa0" },
],
```

**土台の `style`（描き方）**：色（`body` 正面・`top` 上の面・`pillar` 柱）と `style` を書くだけで、土台と柱の絵ができます（`js/platform-art.js`）。

| style | 土台 | 柱 |
| --- | --- | --- |
| `wood` | 板を並べた木目、上は芝生、ふちから草がたれる、側面に小さな花 | 丸太 |
| `stone` | れんがのように石を積んだ模様、すき間にこけ | 石積み |
| `ice` | 半透明の青、表面にななめの光、下につらら | 氷の柱 |
| `gold` | 金の板に彫り模様、ゲーム中はときどき光が横に走る | 金の円柱 |
| `crystal` | 宝石のような三角の面と光 | 水晶の柱 |
| `pumpkin` | かぼちゃのすじ・くり抜いた顔・つるとはっぱ | つるが巻いた木の柱 |
| `steel` | 鉄の板にリベット、上のふちに黄色と黒の注意のしま | 赤い鉄骨（`pillar` の色。ななめの筋交い） |
| `cardboard` | ダンボールの箱、ガムテープ、「天地無用」とグラスの印、上は波の断面 | ダンボールを積んだ柱 |
| （書かない） | 色だけの四角 | 色だけの柱 |

- 見た目が変わるだけで、**当たり判定（キャラが乗れる範囲）はどの style でも同じ四角**です。上の面のふちには、乗れる範囲がわかる明るい線が入ります
- 絵は、テーマを変えたときに1回だけ描いて使い回すので、ゲーム中は重くなりません
- プロフィール画面の見本も、同じ絵を小さくしたものです
- 新しい style を作るときは、`js/platform-art.js` の `STYLES` に、土台（`platform`）と柱（`pillar`）の描き方を足します

### 高さで変わる背景を追加する

`config.js` の `sky.stages` に1行足します（高さの低い順に並べる）。

```js
sky: {
  blend: 1, // 何 m かけて次の背景の色に変わるか
  stages: [
    { height: 0, name: "草原", icon: "🌱" }, // 地上（色はプロフィールで選んだ背景）
    ...
    { height: 9, name: "宇宙", icon: "🚀", top: "#03051a", bottom: "#1b2156", cloud: "#1b2156", clouds: 0, stars: true },
    { height: 14, name: "月", icon: "🌕", top: "#000000", bottom: "#2a2a40", stars: true }, // ← 足した例
  ],
},
```

- `height` に届くと「〇〇に到達！」と出ます。色は `#` から始まる6桁で書きます
- 書いていない項目（色・雲・星）は、1つ前の背景と同じになります

1. `config.js` の `rules` に、名前・アイコン・説明・数値を書く
2. `js/rules.js` の `BEHAVIORS` に、同じ名前で動きを書く
   （「キャラの性質を変える」「毎ステップ何かする」「画面に何か描く」などの入口が用意されている。使い方はファイルの先頭に説明あり）

### タイトル画面の演出

`config.js` の `titleFx` で、タイトル画面の動きを調整できます（時間はすべて秒）。

- 登場：ロゴが1文字ずつ弾んで出る（`logoStart`・`logoStep`）→ タグライン（`taglineAfter`）→ スタートボタン・メニュー（`buttonAfter`）
- ロゴがふわふわ動く速さ（`floatTime`）、キラッと光る間隔（`shineEvery`）、スタートボタンが脈打つ速さ（`pulseTime`）
- 雲（`clouds`。奥 `far` と手前 `near` で、数・速さ・大きさ・濃さを変えられる。タイトル以外の画面の空にも使う）
- 鳥（`birds`。来る間隔・羽数・速さ）
- 後ろのデモの塔（`config.js` の `titleDemo`）：キャラが上から落ちてきて、いい感じに組み合わさって積み上がります（落ちたり崩れたりしません）。1体ごとに向き4通り × 位置7か所を見えないところで試して、落ちずに、低く・まっすぐ・真ん中に収まる置き方を選び、試したときの動きどおりに見せています。前のキャラが落ちきる前に、次のキャラも落ちてきます（`interval`）。積み終わったら少し見せて（`holdTime`）、ふわっと消えて（`fadeTime`）、順番を入れかえて最初から

鳥の色は、プロフィールで選んだ背景の色から作ります。タイトル以外の画面に移ると、演出は止まります。
端末の「視差効果を減らす」が ON のときは、フェードだけになり、鳥・キラッは出ません（デモの塔は、積み上がった形で止まった絵になります）。
動き自体は `css/style.css` の「タイトル画面の演出」と `js/title-fx.js`、背景は `js/game.js` にあります。

### 見た目

`css/style.css` の先頭の `:root { ... }` で、色・フォント・角丸・余白をまとめて変えられます。

### 読み込みが終わらない・ボタンが押せないとき（読み込みの状況の表示）

公開ページの URL の最後に `?debug=1` を付けて開く（例：`https://…/kajiwara-tower-battle/?debug=1`）か、`config.js` の `devMode` を `true` にすると、画面の左下に読み込みの状況が出ます（`js/load-status.js`）。iPhone のように開発者ツールを開けない端末で、原因を探すのに使います。

- 「… 〇〇（〇秒）」：まだ終わっていない読み込み（キャラの画像・data/ の JSON）
- 「✗ 〇〇」：読み込めなかったもの・時間切れになったもの・プログラムのエラー
- 「● スタート：押せる（キャラ 17 / 17）」：スタートが押せるようになった
- 表示はタップを受け取らないので、下のボタンはそのまま押せます

読み込みには時間切れがあります（キャラの画像 10秒・data/ の JSON 8秒）。時間切れになった画像のキャラは飛ばして、残りのキャラで遊べるようにします。

**スタートボタンのアニメーションについて**：スタートボタンの登場・脈打つ動きは、ボタンの外側（`.btn-start-wrap`）に付けています。ボタンそのものにアニメーションを付けて「押したあいだだけ止める」書き方にすると、iPhone の Safari では指を離した瞬間にボタンが動いて、押せなくなります（v1.14.1 で直したバグ）。ほかのボタンに動きを付けるときも、同じようにしてください。

| 自由配置モード | 好きなキャラ（レア度・サイズ違い・イベントのキャラもふくむ全キャラ。反転も）を、タップした場所（空中でも）に置く。置いたキャラはタップで選び、ドラッグで動かす・回転（45度ずつ）・反転・削除。「全部消す」で土台以外を全部消す。物理の停止・再開・止めたまま「1コマ」進める。**ハイスコア・戦績・実績・図鑑には記録しない**（画面の上に「デバッグ中・記録されません」が出つづける）。js/sandbox.js |
| 表示 | 当たり判定の線 / FPS / キャラの数と高さ / 読み込み状況 を、それぞれ ON・OFF（FPS と数値は画面の左上、読み込み状況は左下） |
| 日付を変えてテスト | ゲームの中の日付だけを好きな日時にする（イベントの表示の確認用。時計はそこから進む）。変えているあいだは、画面の上に「テスト日付：10/31」が出る。再読み込みしても続き、**管理者モードを終わると実際の日付に戻る** |
| イベント（確認用） | 「イベント期間中として表示」（日付に関係なくイベントを全部期間中に）と、ハロウィンの勝利数 |
| 次に出すキャラ | 次に出てくるキャラを固定する（「ランダム」に戻すまで、ずっとそのキャラ） |
| 解放状態 | 図鑑 / 実績・称号 / 背景・土台 を選んで「すべて解放」「すべて未解放」。最初に操作する前の状態を保存しておき、「元に戻す」で戻せる（何回操作しても、一番初めの状態に戻る） |
| 出現率のテスト | 好きな回数（初めは1万回）抽選して、レア度ごと・キャラごとの回数と割合、設定の出現率との差を表で出す。偶然では起きにくい大きなずれ（標準偏差の3倍より大きい）は赤くなる |
| データのリセット | ハイスコア / 戦績（1人・対戦） / 図鑑 / 実績・称号 / スタンプ設定 / 解放した背景・土台 / プロフィール（名前・写真） / 設定 を選んで、初めの状態に戻す（プロフィールと設定は、初めはチェックなし）。実行の前に、消える内容の一覧を出して確かめる。「リセットの前に、バックアップのファイルを書き出す」で、先にバックアップを書き出せる |
| オンライン対戦の接続 | 待ち受けやつながり方の状態を表示する |
| 称号「開発者」 | 管理者モードの端末でだけ、称号を選ぶ画面に並ぶ（レジェンドの色） |
| 管理者モードを終わる | この端末から鍵を消す（次は合言葉が必要） |

**オンライン対戦の相手と、公開ランキングへの影響を防ぐしくみ**

- 管理者モードのあいだは、ハイスコアをオンラインのランキングに**送りません**（`js/ranking.js`）
- オンライン対戦では、「次に出すキャラ」・テスト日付・「イベント期間中として表示」を使わず、実際の日付で抽選します（ホストが抽選して相手にも同じキャラが出るため。`js/game.js` の `fair`）
- オンライン対戦の相手に見せるプロフィールには、ハイスコア・順位・実績の数・対戦成績を載せません（データを書きかえられるため。`js/vs-intro.js`）
- 自由配置モードは、ひとりで使うモードです（オンライン対戦中に始めると、対戦は終わります）

### 合言葉の登録（最初に1回だけ）

1. ゲームを開き、タイトル右下のバージョンを7回タップする（合言葉がまだ無いので、登録の画面が出る）
2. 新しい合言葉（8文字以上。ほかで使っていないもの）を入れて「番号を作る」を押す
3. 出てきた1行（`passHash: "…",`）を、`config.js` の `admin` の `passHash: "",` の行と置きかえて、GitHub に上げる
4. もう一度7回タップして、合言葉で開く。開いた端末は、次からは合言葉なしで管理者モードになる

- 合言葉そのものは、どこにも保存されません（config.js には、合言葉から作った元に戻せない番号だけを書きます）。合言葉を忘れたら、同じ手順で新しく登録し直します
- 番号を作る画面は、Live Server（http://127.0.0.1 など）か公開ページ（https）で開いてください（http の別のアドレスでは動きません）
- **注意**：このゲームはファイルを公開しているので、プログラムに詳しい人がブラウザの開発者ツールでプログラムを書きかえれば、こじ開けられます。ふつうに遊ぶ人には開けない、という仕組みです
